# Enterprise-Data-Reconciliation
Enterprise Data Reconciliation &amp; Financial Audit Dashboard built using SQL, Python, Pandas, SQLite, Excel, and Power BI. The project focuses on data extraction, cleaning, reconciliation, currency conversion, and executive dashboard reporting.

## Problem Statement
A company stores data across multiple systems including transaction records, user databases, and exchange-rate files. The objective is to reconcile data, identify inconsistencies, and build an executive dashboard for business reporting.

## Tools Used
- SQL
- Python
- Pandas
- SQLite
- Excel
- Power BI

## Key Features
- Data extraction from SQL and CSV sources
- Data cleaning and transformation
- Currency conversion
- Reconciliation checks
- Interactive Power BI dashboard

## Dashboard KPIs
- Total Revenue
- Total Transactions
- Active Users
- Average Transaction Value
