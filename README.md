# Enterprise-Data-Reconciliation
Enterprise Data Reconciliation &amp; Financial Audit Dashboard built using SQL, Python, Pandas, SQLite, Excel, and Power BI. The project focuses on data extraction, cleaning, reconciliation, currency conversion, and executive dashboard reporting.

## Tools Used
- SQL
- Python
- Pandas
- SQLite
- Excel
- Power BI

## Key Features
- Data extraction from SQL and CSV sources
- Data cleaning and transformation
- Currency conversion
- Reconciliation checks
- Interactive Power BI dashboard

## Problem Statement

A company stores financial and customer data across multiple systems including SQL databases, transaction files, and exchange rate records. The objective of this project is to reconcile data, identify inconsistencies, perform currency conversion, and build an executive dashboard for business reporting and financial auditing.

## Dashboard KPIs

- Total Revenue
- Total Transactions
- Active Users
- Average Transaction Value

## Project Workflow

1. Extract data from SQL and CSV sources
2. Clean and transform datasets using Pandas
3. Merge and reconcile records
4. Perform currency conversion
5. Create audit checks
6. Build an interactive Power BI dashboard
